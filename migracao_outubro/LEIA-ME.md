# Kit inicial: Migração SCPG
1. Copie esta pasta para o Mac mini (ex.: ~/projetos/migracao-scpg).
2. Copie o código-fonte Delphi para legado/delphi/ (sem .exe, .dcu, __history).
3. `git init && git add -A && git commit -m "kit inicial"`
4. `claude` na raiz do projeto, e use o prompt da fase 1 (inventário).
